# MENTALIST

Academia de entrenamiento en español para desarrollar observación, atención, memoria, psicología, lectura muscular, asociación, investigación y concentración.

## Programa anual
- 365 días de entrenamiento.
- 8 disciplinas por día: 2.920 ejercicios en total.
- Cada disciplina genera una variación específica por día, identificada por el número de día y sus parámetros de práctica.
- Al completar los 8 ejercicios, el siguiente día se desbloquea automáticamente.
- Las 8 lecciones originales se conservan como Día 1; los usuarios que ya las completaron continúan en Día 2.
- 365 retos diarios independientes, separados de las lecciones del programa.
- Cada reto diario usa una serie propia y cambia según la fecha de inicio del programa.

## Progreso y privacidad
- XP, días completados, ejercicios y retos diarios se guardan en localStorage del navegador.
- No se requiere una cuenta, Firebase ni servicios de pago.
- El progreso vive en el navegador/dispositivo donde se utiliza la página; no se sincroniza entre dispositivos.

## Publicación con GitHub Pages
1. Abre **Settings** del repositorio.
2. En el menú lateral entra a **Pages**.
3. Selecciona **Deploy from a branch**.
4. Elige la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save**.

## Nota de rigor
La psicología y la observación no permiten leer pensamientos ni detectar mentiras con certeza a partir de gestos. Las prácticas de lectura muscular se realizan con consentimiento, sin presionar muñecas o brazos, y no presentan el movimiento ideomotor como un código infalible.
