# MENTALIST

Academia de entrenamiento en español para desarrollar observación, atención, memoria, psicología, lectura muscular, asociación, investigación y concentración.

## Programa anual
- 365 días de entrenamiento.
- 8 ejercicios por día: 2.920 ejercicios en total.
- Cada día genera una variación propia en cada disciplina, con nuevos datos, escenas, palabras, pistas, contextos y preguntas.
- Cada ejercicio completado queda guardado y no vuelve a aparecer como pendiente.
- Al completar los 8 ejercicios de un día, el día siguiente se desbloquea automáticamente.
- Las 8 lecciones originales se conservan como Día 1; los usuarios que ya las completaron continúan en Día 2 sin perder XP.
- Los ejercicios de lectura muscular hablan de muñeca y antebrazo, siempre con consentimiento y sin aplicar presión.
 
## Retos diarios independientes
- Serie adicional de 365 retos, separada del programa de 8 disciplinas.
- Cada reto se elige según el número de día desde la primera visita a esta versión.
- No reutiliza las lecciones del programa ni ocupa su lugar.
- Responder un reto y registrarlo suma experiencia por separado.

## Progreso y privacidad
- XP, días completados, ejercicios y retos diarios se guardan en localStorage del navegador.
- No se requiere una cuenta, Firebase ni servicios de pago.
- El progreso vive en el navegador/dispositivo donde se utiliza la página; no se sincroniza entre dispositivos.

## Publicación con GitHub Pages
1. Abre **Settings** del repositorio.
2. En el menú lateral entra a **Pages**.
3. Selecciona **Deploy from a branch**.
4. Elige la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save**.

## Nota de rigor
La psicología y la observación no permiten leer pensamientos ni detectar mentiras con certeza a partir de gestos. Las prácticas ideomotoras son ambiguas: sirven para estudiar pequeños movimientos, no para tratar el cuerpo como un código infalible.
