# MENTALIST

Academia interactiva en español para entrenar observación, atención, memoria, psicología, lectura muscular, asociación de ideas e investigación.

## Contenido
- 8 lecciones con fundamento, demostración y práctica interactiva.
- Ejercicios de observación, efecto Stroop, memoria, interpretación de señales, asociación, deducción y concentración.
- Rutas de aprendizaje progresivas.
- XP, niveles, racha y registro de lecciones guardados localmente en el navegador.
- Diseño adaptable a escritorio, tabletas y móviles.
- No requiere cuentas, Firebase ni servicios de pago.

## Publicar con GitHub Pages
1. Abre **Settings** del repositorio.
2. En el menú lateral entra a **Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama **main** y la carpeta **/(root)**.
5. Pulsa **Save**.

Después de que GitHub termine la publicación, la web estará disponible en:
https://hyisx98754-beep.github.io/Mentalist-Test/

## Privacidad y límites
El progreso se guarda en el almacenamiento local del navegador donde se utiliza la página. No se envía a un servidor. Las lecciones de psicología explican límites importantes: un gesto aislado no demuestra una mentira y los movimientos ideomotores no revelan automáticamente una palabra o pensamiento.
